# Documentación de producto — Dwell Havana

Esta carpeta contiene las decisiones de producto, los flujos editoriales y las guías de uso.

## Índice

1. `roadmap.md` — visión, fases, trabajo pendiente y orden de implementación.
2. `05-flujos-editoriales.md` — ingesta, moderación, acceso editorial y sindicación pull.
3. `07-guia-acceso-colaboradores.md` — uso del acceso por invitación para editoras y colaboradores.
4. `contenido-placeholder.md` — dónde está el contenido de ejemplo y cómo sustituirlo.

## Convención

- `PRODUCT/` describe qué debe hacer el producto, quién puede usarlo y en qué orden se implementan las fases.
- `Tech/` describe cómo funciona la implementación actual y cómo se configura.
- `Idea/` conserva decisiones iniciales y documentos de exploración.

Si un documento de producto y el código actual discrepan, el código describe el estado implementado y el documento de producto describe el estado decidido o pendiente. Actualiza ambos cuando una fase pase a producción.
