# Dwell Havana — Design Direction

## Core Concept

Dwell Havana should be designed as an editorial platform
focused on architecture, interiors, culture and distinctive
homes in Havana.

The website should feel closer to a contemporary design
magazine than to a traditional real-estate portal.

Primary reference:
Dwell Magazine / Dwell.com

The reference should influence the visual philosophy,
not result in a direct imitation.

---

## Design Principles

1. Photography first
2. Editorial composition
3. Strong typography
4. Generous whitespace
5. Structured grid
6. Asymmetric compositions
7. Minimal interface
8. Authentic visual storytelling
9. Contemporary Cuban identity
10. Timeless rather than trendy

---

## Visual Personality

Editorial
Architectural
Human
Contemporary
Cuban

Avoid:

- Corporate aesthetics
- Traditional real-estate layouts
- Luxury clichés
- Tourism clichés
- Excessive decoration
- Excessive animation
- Generic card-based interfaces

---

## Photography

Photography is the primary visual element.

Prioritize:

- Architecture
- Interiors
- Materials
- Light
- Details
- People
- Everyday life
- Texture
- Imperfection
- Context

Photography should communicate how spaces are actually
experienced and inhabited.

Avoid excessive staging and generic stock photography.

---

## Layout

Use a structured editorial grid.

Recommended:

- 12-column desktop grid
- Strong horizontal rhythm
- Large image areas
- Variable image sizes
- Asymmetric compositions
- Generous whitespace
- Occasional grid-breaking elements

The grid should create order without making the website
feel rigid.

---

## Homepage

Recommended structure:

1. Featured property / editorial story
2. Journal
3. Featured homes
4. Architecture / design story
5. Havana editorial content
6. About Dwell Havana
7. Contact / footer

The homepage should feel like a digital magazine cover,
not a property catalogue.

---

## Navigation

Keep navigation minimal.

Recommended:

- Journal
- Properties
- About

Optional:

- Places
- Search

Avoid excessive navigation categories during the first version.

---

## Properties

Properties should be presented editorially.

Each property should communicate:

- Image
- Name
- Location
- Architectural character
- Short editorial description

Avoid making the initial experience feel like a database.

Filters should remain minimal.

---

## Property Detail

Recommended structure:

1. Full-width hero image
2. Property title
3. Location
4. Editorial introduction
5. Photography gallery
6. Architecture
7. Interior
8. Story / history
9. Property information
10. Contact CTA

Photography and narrative should appear before
the commercial CTA.

---

## Journal

Editorial categories may include:

- Architecture
- Interiors
- People
- Places
- Culture
- Design

The Journal should establish Dwell Havana as a
design authority rather than simply a property seller.

---

## Typography

Typography should feel:

- Editorial
- Contemporary
- Architectural
- Highly readable

Use a strong display typeface combined with a clean
body typeface.

Avoid overly decorative luxury typography.

---

## Color

Primary palette:

- Warm white / off-white
- Soft black
- Charcoal
- Light neutral gray

Optional restrained accent inspired by Havana.

Accent color should support the photography rather than
compete with it.

Avoid stereotypical Cuban color palettes.

---

## UI

Minimal interface.

Use:

- Thin dividers
- Small metadata
- Simple buttons
- Subtle hover states
- Clean galleries
- Fullscreen imagery
- Minimal icons

Avoid:

- Heavy cards
- Excessive shadows
- Gradients
- Large rounded UI components
- Excessive badges
- Visual clutter

---

## Motion

Motion should be subtle and editorial.

Recommended:

- Image reveal
- Soft transitions
- Subtle image scaling
- Gallery transitions
- Minimal page transitions

Avoid:

- Excessive parallax
- Large animations
- Decorative motion
- Complex 3D effects

---

## Mobile

Mobile must be treated as a primary experience.

Priorities:

1. Photography
2. Typography
3. Story
4. Navigation
5. Property information

Do not simply compress the desktop layout.

---

## Brand Positioning

Dwell Havana should feel like:

"An editorial guide to Havana's architecture,
design and distinctive homes."

Rather than:

"Another real-estate website in Havana."

---

## Reference Rule

Use Dwell as inspiration for:

- Editorial thinking
- Photography hierarchy
- Grid systems
- Typography
- Content structure
- Visual rhythm
- Magazine-like storytelling

Do NOT copy:

- Logo
- Exact typography
- Exact layouts
- Colors
- Components
- Photography
- Brand assets
- Distinctive visual trademarks

Dwell Havana must develop its own visual identity.
